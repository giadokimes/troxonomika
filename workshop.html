01

Από πού παίρνει δεδομένα

Το εργαλείο διαβάζει τα πραγματικά αρχεία του δημόσιου repo σου από το raw.githubusercontent.com. Μόνο ανάγνωση, χωρίς κωδικούς, χωρίς server. Οι αλλαγές εφαρμόζονται μέσα στον browser του κινητού και το αποτέλεσμα κατεβαίνει ως αρχείο. Τίποτα δεν αποστέλλεται αλλού· οι συνταγές αποθηκεύονται μόνο τοπικά στη συσκευή.

ΒΗΜΑ 1Σύνδεση
ΒΗΜΑ 2Συνταγή
ΒΗΜΑ 3Εφαρμογή
ΒΗΜΑ 4Έλεγχος
ΒΗΜΑ 5Λήψη
ΒΗΜΑ 6Ανέβασμα

Ροή κάθε φορά: επικολλάς τη συνταγή που σου δίνω → Εφαρμογή → Λήψη → ανεβάζεις τα αρχεία στο GitHub (Add file → Upload files). Το εργαλείο μένει μόνιμα στο repo ως workshop.html.

02

Αρχεία repo

Πάτα ένα αρχείο για να φορτωθεί στην εργασία. Το CRLF σημαίνει γραμμές Windows — κανονικοποιούνται αυτόματα πριν την εφαρμογή.

03

Συνταγή αλλαγών

Μια συνταγή = λίστα από αρχεία και λειτουργίες. Τύποι: replace (εύρεση→αντικατάσταση), regex, append (προσθήκη στο τέλος αν λείπει δείκτης), bump (αύξηση αριθμού έκδοσης). Σύρε εδώ ένα .json ή επικόλλησέ το.

04

Εφαρμογή & λήψη

Αν ένα μπλοκ δεν βρεθεί αλλά υπάρχει ήδη το νέο, σημειώνεται ως «ήδη εφαρμοσμένο» και παρακάμπτεται — έτσι η ίδια συνταγή τρέχει με ασφάλεια κάθε φορά.

Ολική αντικατάσταση αρχείου

Για ολόκληρο νέο αρχείο: διάλεξε όνομα, επικόλλησε το περιεχόμενο, κατέβασέ το.

05

Έλεγχος ποιότητας

Πραγματικός έλεγχος σύνταξης στο αποτέλεσμα (JS compile, JSON parse, ισοζύγια αγκυλών/braces, δομή HTML).

Δεν έχει γίνει έλεγχος ακόμη.
06

Βιβλιοθήκη συνταγών

Αποθηκεύονται τοπικά στη συσκευή. Οι έτοιμες συνταγές είναι ασφαλείς να τρέχουν επαναληπτικά.
