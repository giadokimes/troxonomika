02

Απόκτηση μοντέλων

Αν έχεις ήδη τα αρχεία στη συσκευή, φόρτωσέ τα απευθείας. Μπαίνουν στην ίδια cache που διαβάζουν τα υπόλοιπα εργαλεία.

Οποιαδήποτε απευθείας διεύθυνση. Ελέγχεται ότι είναι πραγματικό ONNX και όχι σελίδα σφάλματος.

Τα πακέτα Python περιέχουν έτοιμα .onnx και λεξικά. Το εργαλείο βρίσκει ζωντανά το wheel, το ξεζιπάρει μέσα στον browser και σου δείχνει τα πραγματικά αρχεία. Δεν χρειάζεται Python.

Δεν έχει γίνει αναζήτηση.

Δώσε αναγνωριστικό αποθετηρίου και το εργαλείο εμφανίζει τα πραγματικά αρχεία που είναι δημοσιευμένα.

—

Σαρώνει ολόκληρο το δέντρο του αποθετηρίου και βρίσκει κάθε .onnx και λεξικό, σε οποιονδήποτε φάκελο.

05

Μόνιμη εγκατάσταση στο repo

Η cache αρκεί για να δουλέψουν τα εργαλεία σε αυτή τη συσκευή. Για να δουλεύουν παντού, ανέβασε τα αρχεία στον φάκελο models/ με τα σωστά ονόματα.

GitHub → Add file → Upload files → φάκελος models/ → ονόματα det.onnx, rec.onnx, cls.onnx, el_dict.txt. Το «Λήψη όλων» τα κατεβάζει ήδη με αυτά τα ονόματα.
06

Οδηγός

1Το 0.01 MB ✕ στη λήψη σημαίνει 404: το αρχείο δεν υπάρχει στο repo. Δεν φταίει το δίκτυο.
2Χρησιμοποίησε PyPI wheel για να πάρεις έτοιμα ONNX χωρίς υπολογιστή. Τα αρχεία που εμφανίζονται είναι τα πραγματικά περιεχόμενα του πακέτου.
!Το λεξικό πρέπει να είναι εκείνο του συγκεκριμένου rec. Η επικύρωση συγκρίνει κλάσεις εξόδου με λεξικό+1 και το δείχνει καθαρά.
!Αν το λεξικό δεν περιέχει ελληνικούς χαρακτήρες, το μοντέλο δεν μπορεί να διαβάσει ελληνικά — θα βγάζει λατινικά/κινέζικα. Η επικύρωση το επισημαίνει αντί να το κρύψει.
✓Ό,τι κατεβαίνει αποθηκεύεται τοπικά. Καμία εικόνα υπόθεσης δεν αποστέλλεται πουθενά.
